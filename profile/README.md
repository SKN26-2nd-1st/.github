## Team Identity

우리는 단순 분석 결과를 만드는 팀이 아니라  
데이터 수집 → 전처리 → 모델링 → 평가 → 배포까지  
전 과정을 설계하는 엔지니어링 중심 팀입니다.

---

## Core Capabilities

- 데이터 분석 및 EDA
- 머신러닝 모델 설계 및 평가
- 불균형 데이터 처리 및 성능 지표 최적화
- 재현 가능한 실험 구조 설계
- Git 기반 협업 (PR / Issue / Convention)
- Docker 기반 실행 환경 구성

---

## Working Method

- Issue 기반 작업 분리
- Branch 전략 준수
- Conventional Commit 사용
- PR 리뷰 후 Merge
- 실험 결과 및 모델 근거 문서화

---

## Repository Philosophy

각 프로젝트는 독립된 저장소로 관리하며  
다음 원칙을 따릅니다:

- 구조화된 폴더 구성
- 데이터 분리 관리
- 모델 버전 관리
- 산출물 기록 유지
